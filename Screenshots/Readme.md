## Format tips

- **PNG** with a transparent-ish or dark background works well against GitHub's dark theme (which is the default for most viewers).
- Compress heavy screenshots with [tinypng.com](https://tinypng.com/) — 3–5× smaller for no perceptible quality loss.
- Aim for < 500 KB per image so the README renders fast on mobile.
